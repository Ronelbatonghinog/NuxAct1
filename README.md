# Nuxt.js Personal Profile Website

A responsive two-page personal profile website built with Nuxt 3, Vue, and Tailwind CSS.

## Pages
- `/` — Homepage with introduction, avatar, welcome message, and navigation.
- `/profile` — Personal information, education, skills, interests, and hobbies.

## Run locally
1. Install Node.js (LTS).
2. Open this project folder in VS Code.
3. Open the terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed in the terminal (usually `http://localhost:3000`).

## Personalize the content
Replace `Your Name`, `Your Course`, `Your School Name`, the email, location, skills, interests, and hobbies in:
- `app/pages/index.vue`
- `app/pages/profile.vue`

The avatar is an initials-based placeholder. Replace it with a real image in `public/` if desired.

## Build
Run `npm run build` to create a production build.
